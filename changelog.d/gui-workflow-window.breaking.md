The GUI is one workflow window instead of a six-step wizard: Home, then Data (load and check the trace), Prepare, Retrieve and Analyse (dispersion and uncertainty), with one primary action in the top bar and the settings or a replay script on request. `croak.gui.run_wizard` is now `croak.gui.run_gui` and `croak.gui.Wizard` is now `croak.gui.MainWindow`; the `croak-gui` command is unchanged.
