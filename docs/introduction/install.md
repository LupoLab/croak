# Get and install croak

Choose the installation route that matches how you want to work. Both routes
use the same retrieval library and require Python 3.14 or later; the installation
instructions explain how `uv` can provide Python for you.

- **Use the graphical interface:** follow [Installing the GUI](../getting_started/gui.md).
  This route installs a command you can launch without writing Python code.
- **Use croak from Python:** follow [Installation](../getting_started/installation.md).
  This covers a project environment, optional features, platforms, and
  installation from a source checkout for the bundled example scripts.

```{toctree}
:maxdepth: 1

../getting_started/gui
../getting_started/installation
```

After installation, read the [capabilities overview](../reference/features.md)
and [choose an interface](interfaces.md). Contributors can find the development
checks in the [developer's guide](../developer_guide/environment.md).
