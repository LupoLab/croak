# Measurement fundamentals and conventions

A FROG measurement records a nonlinear signal spectrum as a delay is varied.
Retrieval uses a model of that signal to infer the pulse. Start with the
measurement framework and supported interactions, then establish the units,
frequency axes, and Fourier convention used in your calculation.
