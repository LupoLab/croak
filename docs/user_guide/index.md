# User guide

This guide follows a retrieval from the measurement and its data to the
interpretation of a pulse. Each topic connects practical choices to the physics
and numerical methods behind them. Read the chapters in order for the complete
workflow, or use the chapter list to find a particular procedure or derivation.

If you are new to croak, begin with the [introduction](../introduction/index.md)
and [first retrieval](../tutorials/01_first_retrieval.md). The
[examples gallery](../examples/index.md) provides runnable applications of the
topics below.
