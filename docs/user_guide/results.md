# Interpreting results

Inspect the measured and predicted traces, the residual, and the retrieved
spectral and temporal profiles together. A duration is one summary of a pulse;
it does not describe satellites, phase, or agreement with the measurement.
Comparisons also require consistent field definitions and reference planes.
